OBJETIVO
--------
1. Permitir dois fluxos de cadastro/login:
   (a) Google (mantem o existente, refatorado para emitir JWT proprio)
   (b) Email + senha com confirmacao por codigo de 6 digitos enviado por email
       via Brevo (free-plan, API HTTP transactional-emails)

2. Apos autenticar (em qualquer um dos fluxos), o backend emite um JWT proprio.
   Todas as rotas (exceto as publicas de auth) passam a exigir esse token via
   [Authorize] global + app.UseAuthentication()/UseAuthorization().

3. Tornar Artista.UsuarioId uma FK real para Usuario.Id, com nav property
   bidirecional e configuracao via Fluent API.

B. FLUXO DE CADASTRO LOCAL (email + senha)
================================================================================

Politica de senha:
  - Minimo 8 caracteres
  - Maximo 20 caracteres
  - Pelo menos 1 letra maiuscula
  - Pelo menos 1 simbolo (nao alfanumerico)
  - Hash com BCrypt.Net-Next (work factor 11-12)

Codigo de verificacao:
  - 6 digitos numericos gerados com RNG cripto-seguro
  - Expira em 10 minutos
  - Maximo 5 tentativas erradas antes de invalidar
  - Reenvio: cooldown de 60 segundos entre cada, max 3 por hora
  - Armazenado como HASH (HMAC-SHA256 com pepper OU bcrypt)

Endpoints:

  POST /api/Auth/Cadastrar             [AllowAnonymous]
    Body: { email, senha, nomePerfil, dataNascimento, pronome? }
    Comportamento:
      - Valida formato/forca da senha
      - Checa duplicidade de email e NomePerfil
      - Bloqueia se email ja existe com ProvedorAutenticacao=Google
        (mensagem clara: "Esse email ja foi cadastrado via Google,
        use o login do Google.")
      - Cria Usuario COM EmailConfirmado=false, ProvedorAutenticacao=Local
      - Gera codigo de 6 digitos, grava hash em CodigoVerificacaoEmail
      - Envia email via Brevo
      - Retorna 204 No Content
    Importante: usuario fica criado mas NAO pode logar ate confirmar email.

  POST /api/Auth/ConfirmarEmail        [AllowAnonymous]
    Body: { email, codigo }
    Comportamento:
      - Valida codigo nao expirado, nao consumido, dentro do limite de
        tentativas
      - Marca CodigoVerificacaoEmail.Consumido=true
      - Marca Usuario.EmailConfirmado=true
      - Emite JWT + RefreshToken
    Retorna: { accessToken, refreshToken, expiresIn }

  POST /api/Auth/ReenviarCodigo        [AllowAnonymous]
    Body: { email }
    Comportamento:
      - Rate-limit: cooldown 60s, max 3/hora
      - Invalida codigos anteriores nao consumidos do mesmo email
      - Gera novo codigo, envia
      - Retorna 204
    Mensagem generica se email nao existe (nao revelar enumeracao).

  POST /api/Auth/LoginLocal            [AllowAnonymous]
    Body: { email, senha }
    Comportamento:
      - Bloqueia se EmailConfirmado=false
      - Bloqueia se ProvedorAutenticacao != Local
      - Verifica senha (BCrypt.Verify)
      - Emite JWT + RefreshToken
    Retorna: { accessToken, refreshToken, expiresIn }
    Mensagens de erro genericas ("credenciais invalidas") para nao
    revelar se o email existe.

C. FLUXO GOOGLE (refatorar)
================================================================================

  POST /api/Auth/ValidarTokenGoogle    [AllowAnonymous]
    Body: { tokenGoogle }
    Comportamento:
      - Valida ID token Google (igual hoje)
      - Upsert do Usuario:
          - Se existe e ProvedorAutenticacao=Local: BLOQUEAR com mensagem
            clara ("Esse email ja foi cadastrado com senha local.")
          - Se nao existe: cria com ProvedorAutenticacao=Google,
            EmailConfirmado=true
          - Se ja existe Google: apenas autentica
      - Emite JWT + RefreshToken NOSSO (nao mais o payload Google)
    Retorna: { accessToken, refreshToken, expiresIn }

UsuarioService.CadastrarUsuario / ObterUsuarioPorToken / AutenticarUsuario:
  - Devem parar de validar token Google em cada request
  - Passam a ler claims do JWT via HttpContext.User
  - Ex.: var usuarioId = int.Parse(User.FindFirst("sub")!.Value);

D. JWT + AUTHORIZATION
================================================================================

Pacote NuGet a adicionar:
  - Microsoft.AspNetCore.Authentication.JwtBearer

Configuracao do token (access token):
  - Algoritmo: HS256 (HMAC-SHA256)
  - Claims:
      sub          = Usuario.Id
      email        = Usuario.Email
      nomePerfil   = Usuario.NomePerfil
      provedor     = "Google" ou "Local"
      exp          = now + 60 min
      iss          = "SMT.Back.Comissoes"
      aud          = "SMT.Front.Comissoes"
  - SigningKey: minimo 32 bytes, em user-secrets/env var
                (NUNCA no appsettings.json versionado)

Refresh token:
  - String opaca aleatoria (32+ bytes, Base64Url)
  - Expira em 5 dias
  - Hash armazenado em RefreshToken.TokenHash
  - Rotation: a cada uso, revoga o antigo (Revogado=true,
    SubstituidoPor=novoId) e emite novo par

Endpoint de refresh:
  POST /api/Auth/RefreshToken          [AllowAnonymous]
    Body: { tokenAntigo, refreshTokenAntigo }
    Comportamento:
      - Aceita access token EXPIRADO mas com assinatura valida
        (ValidateLifetime=false so neste endpoint)
      - Valida refresh token: existe, nao revogado, nao expirado,
        pertence ao mesmo usuario do access token
      - Revoga o refresh antigo
      - Emite novo par (access + refresh)
    Retorna: { accessToken, refreshToken, expiresIn }

Endpoint de logout:
  POST /api/Auth/Logout                [Authorize]
    Body: { refreshToken }
    Comportamento: marca o refresh token como Revogado=true
    Retorna: 204

Authorization global em Program.cs:

  builder.Services
      .AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
      .AddJwtBearer(options =>
      {
          options.TokenValidationParameters = new TokenValidationParameters
          {
              ValidateIssuer = true,
              ValidateAudience = true,
              ValidateLifetime = true,
              ValidateIssuerSigningKey = true,
              ValidIssuer = builder.Configuration["Jwt:Issuer"],
              ValidAudience = builder.Configuration["Jwt:Audience"],
              IssuerSigningKey = new SymmetricSecurityKey(
                  Encoding.UTF8.GetBytes(builder.Configuration["Jwt:SigningKey"]!)),
              ClockSkew = TimeSpan.Zero
          };
      });

  builder.Services.AddAuthorization();

  // Policy global - todas as rotas exigem auth
  builder.Services.AddControllers(o =>
  {
      var policy = new AuthorizationPolicyBuilder()
          .RequireAuthenticatedUser()
          .Build();
      o.Filters.Add(new AuthorizeFilter(policy));
  });

  // ... resto ...

  app.UseAuthentication();   // ORDEM IMPORTA: Authentication ANTES de Authorization
  app.UseAuthorization();

Rotas publicas (marcar com [AllowAnonymous]):
  - POST /Auth/Cadastrar
  - POST /Auth/ConfirmarEmail
  - POST /Auth/ReenviarCodigo
  - POST /Auth/LoginLocal
  - POST /Auth/ValidarTokenGoogle
  - POST /Auth/RefreshToken

Todas as demais rotas (Usuario/*, Interacao/*, etc.) exigem JWT.
